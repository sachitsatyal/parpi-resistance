# PARP-inhibitor resistance score (single-cell)

Upload single-cell counts and get a per-cell olaparib-resistance score with
uncertainty and the pathways behind it, plus pathway dose-response curves.

Built and deployed automatically from GitHub; the model card on the linked
model repository lists every evaluation number and limitation.
**Research use only — not a diagnostic.**
